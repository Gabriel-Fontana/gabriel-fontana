## Sobre Mim

Sou um entusiasta de **Cloud e DevOps**, focado em construir soluções escaláveis, automatizar pipelines de deploy e entregar infraestrutura de qualidade em ambientes em nuvem.

- Habilidades: AWS, Terraform, Docker, Kubernetes, CI/CD pipelines  
- Especialidade: Automação, monitoramento e boas práticas de arquitetura cloud  
- Forte em scripting, infraestrutura como código e fluxos de deploy eficientes

## Projetos Selecionados

- [`cloud-automation`](https://github.com/GabrielFontana/cloud-automation) – Scripts e módulos Terraform para automação de infraestrutura.  
- [`k8s-deployer`](https://github.com/GabrielFontana/k8s-deployer) – Gerenciamento de deploys Kubernetes com CI/CD.  
- [`ci-cd-pipelines`](https://github.com/GabrielFontana/ci-cd-pipelines) – Templates de pipelines GitHub Actions / GitLab CI/CD.
